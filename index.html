scs-rclient Flatpak Repository

Automated Flatpak repository hosting builds of the scs-rclient desktop application.

1. Add Flathub runtime dependencies

flatpak remote-add --if-not-exists --user flathub https://dl.flathub.org/repo/flathub.flatpakrepo

2. Add the repository

Add this repository to your local Flatpak installation:

flatpak remote-add --if-not-exists --user scs-rclient https://anthony1x6000.github.io/scs-rclient/online.anthonyis.scs-rclient.flatpakrepo

3. Install scs-rclient

Install the application from the repository:

flatpak install --user scs-rclient online.anthonyis.scs-rclient

4. Automatic updates

Once installed, update scs-rclient with your other Flatpak packages at any time:

flatpak update

5. Run the application

flatpak run online.anthonyis.scs-rclient

Source code and build workflows available on GitHub.
